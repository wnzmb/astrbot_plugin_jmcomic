# AstrBot JMComic 插件

漫画站 QQ 机器人插件，基于 [jmcomic](https://github.com/hect0x7/JMComic-Crawler-Python) 库开发，支持搜索、查详情、评论翻页、下载 PDF/ZIP、批量下载、按章节选择、每日签到、收藏夹管理、排行榜、随机抽漫、下载历史、敏感词自动转拼音、简繁自动转换等功能，所有参数均可在配置页自定义。

---

## 安装

1. 在 AstrBot 管理面板 → 插件 → 安装插件 → 从链接安装
2. 填入仓库地址：`https://github.com/wnzmb/astrbot_plugin_jmcomic`
3. 安装完成后，点击插件齿轮图标，填写配置：
   - 客户端类型：api（推荐，功能全）或 html（支持分类筛选）
   - 用户名：你的站点账号（可选，签到/收藏需要）
   - 密码：你的站点密码（可选）
   - 镜像站域名：你能访问的镜像站（支持多个，用英文逗号分隔，自动切换可用的）
   - 号主ID `owner_ids`：JM 账号号主的发送者 ID，多个用英文逗号分隔；签到、收藏、用户信息只允许号主使用。QQ 官方机器人填 openid，可先发 `/jmwhoami` 查看
   - 下载并发数：根据自己网络调整
   - 搜索每页条数：默认10条，可改5-20
   - 文件发送限额：默认每日 100 个、每小时 50 个（QQ 官方限制），插件会本地计数并在超限时提示
   - PDF/ZIP 合并章数 `pdf_group_size`：默认 5，表示每 5 章合并一个 PDF 或 ZIP；填 1 表示每章一个

> 配置页使用“短标题 + 下方详细说明”的布局，数值项可以直接拖滑杆；说明文字不会再挤在标题里被截断。

### 依赖要求

- **jmcomic >= 2.7.9**（推荐，完整功能；`requirements.txt` 会自动安装/升级）
- 版本能力说明：评论翻页需 2.7.3+，下载耗时统计需 2.7.4+，删除收藏需 2.7.6+，每日签到需 2.7.7+
- 如版本过低，在 AstrBot 后端 Python 环境执行：`pip install -U jmcomic`

### 客户端类型说明

| 类型 | 优势 | 限制 |
|---|---|---|
| **api**（推荐） | 收藏添加/删除、评论翻页、每日签到、域名自动更新 | 不支持分类筛选 category |
| **html** | 支持分类筛选 category/sub_category | 收藏添加报错、评论最多10条不翻页、总数解析不出 |

> 需要收藏/签到/评论翻页选 api；需要按分类浏览选 html。切换后需重启插件生效。

## 指令列表

### 🔍 搜索

| 指令 | 用法 | 功能 |
|---|---|---|
| `/jms` | `/jms 关键词 [页码] [排序]` | 全站搜索 |
| `/jma` | `/jma 作者名 [页码] [排序]` | 按作者搜索 |
| `/jmt` | `/jmt 标签名 [页码] [排序]` | 按标签搜索 |
| `/jmr` | `/jmr 角色名 [页码] [排序]` | 按角色搜索 |
| `/jmw` | `/jmw 原作名 [页码] [排序]` | 按原作搜索 |

### 📖 详情

| 指令 | 用法 | 功能 |
|---|---|---|
| `/jmv` | `/jmv <id> [选项]` | 查漫画详情（含章节列表、标签、人物、作品） |
| `/jmlist` | `/jmlist <id> [页码]` | 单独查看全部章节列表（纯文本，不发封面） |
| `/jmc` | `/jmc <id> [页码]` | 查看评论（支持翻页、回复楼、剧透标记） |

### ⬇️ 下载

| 指令 | 用法 | 功能 |
|---|---|---|
| `/jm` | `/jm <漫画id>` | 下载整本，按后台 `pdf_group_size` 合并 PDF（默认每 5 章一个） |
| `/jm` | `/jm <章节id>` | 自动识别为单章，发一个 PDF |
| `/jm` | `/jm id1,id2,id3` | 批量下载，支持漫画/章节 ID 混合 |
| `/jm` | `/jm <id> -c 31` | 只下第 31 章 |
| `/jm` | `/jm <id> -c 31-40` | 下第 31 到 40 章，按后台设置合并 |
| `/jm` | `/jm <id> -c 31,35,40` | 下指定章节，按后台设置合并 |
| `/jmzip` | `/jmzip <漫画id>` | 下载整本，按后台 `pdf_group_size` 合并 ZIP（默认每 5 章一个） |
| `/jmzip` | `/jmzip <章节id>` | 自动识别为单章，发一个 ZIP |
| `/jmzip` | `/jmzip id1,id2,id3` | 批量下载，支持漫画/章节 ID 混合 |
| `/jmzip` | `/jmzip <id> -c 31-40` | 只下指定章节，按后台设置合并 ZIP |
| `/jmphoto` | `/jmphoto <id>` | 等同 `/jm <id>`，兼容旧命令 |

> **PDF/ZIP 合并章数**：不再支持命令里的 `-g`，统一在插件配置页修改 `pdf_group_size`。默认 `5` 表示所有多章漫画每 5 章合并一个 PDF 或 ZIP；改成 `1` 表示每章一个。批量或 `-c` 选章同样按这个设置合并。

> **为什么删除 `/jmlong`**：长图 PNG 体积比 PDF/ZIP 大很多，传输慢且容易触发平台限制；如果 AstrBot 开启了图片压缩，长图还会被压糊甚至直接损坏。需要单章看图请用 `/jm <章节id>`。

> **QQ 文件限额**：QQ 官方机器人每日最多 100 个文件、每小时最多 50 个。PDF/ZIP 默认每 5 章合并一次就是为了减少文件数；达到限额后插件会停止并提示剩余数量，已下载的图片会保留缓存，稍后可用 `-c` 继续。

**文件命名规则**：

| 输出 | 文件名 |
|---|---|
| 单章 PDF/ZIP | `JM{章节id}_{漫画标题}_{章节标题}.pdf/.zip` |
| 多章合并 PDF/ZIP | `JM{漫画id}_{漫画标题}_{起始章}-{结束章}.pdf/.zip` |

单章同时带漫画标题和章节标题；如果漫画标题与章节标题相同，会自动去重。多章合并用“漫画标题 + 章节范围”，多章 ZIP 内按 `P{章节id}_{章节标题}/` 目录保存。

### ⭐ 账号（仅号主）

账号类命令只允许配置在 `owner_ids` 里的号主使用；管理员不会自动获得这些权限。

| 指令 | 用法 | 功能 |
|---|---|---|
| `/jmcheckin` | `/jmcheckin` | 每日签到领金币经验 |
| `/jmme` | `/jmme` | 用户信息面板 |
| `/jmfav` | `/jmfav` | 收藏夹文件夹列表 |
| `/jmfav` | `/jmfav <文件夹id>` | 查看指定收藏夹内容 |
| `/jmfav` | `/jmfav add <漫画id>` | 添加收藏（先检查是否已收藏，避免反向操作） |
| `/jmfav` | `/jmfav del <漫画id>` | 移除收藏（先检查是否已收藏） |
| `/jmwhoami` | `/jmwhoami` | 查看自己的发送者 ID，用于配置号主 |

### 📊 其他

## 排序参数

搜索类指令都支持排序参数，加在最后面就行。

| 参数 | 说明 |
|---|---|
| `mr` | 最新发布（默认） |
| `mv` | 最多浏览 |
| `mp` | 最多页数 |
| `tf` | 最多收藏 |
| `tr` | 评分最高 |
| `md` | 最多评论 |

**示例**：
```
/jms jk mv        # 按最多浏览排序
/jms jk 2 tf      # 第2页 + 最多收藏
/jma MrBlack mv   # 作者搜索 + 最多浏览
```

💡 搜索小提示：建议只打前几个关键词，打全容易因为网站标题简繁混杂漏结果。

搜索结果现在会显示总结果数，例如 `第1页，第1-10条，共 123 条`。

## /jmv 详情精简选项

可以加参数去掉详情中的某些字段：

| 参数 | 说明 |
|---|---|
| `-author` | 去掉作者行 |
| `-work` | 去掉作品行 |
| `-role` | 去掉人物行 |
| `-tag` | 去掉标签行 |
| `-pic` | 不发送封面（默认发送） |

**示例**：
```
/jmv 123456              # 正常发全部
/jmv 123456 -role        # 去掉人物
/jmv 123456 -work        # 去掉作品
/jmv 123456 -author      # 去掉作者
/jmv 123456 -role -work  # 去掉人物和作品
/jmv 123456 -pic         # 不发送封面
```

## 分页说明

- 每页显示 10 条结果
- 第 2 页 = 第 11-20 条
- 第 3 页 = 第 21-30 条
- 以此类推

回复最后会自动带下一页的指令，直接复制发送就行。

## 其他说明

- **数据存储**：所有下载文件和配置都保存在 `data/plugin_data/astrbot_plugin_jmcomic/` 目录下，插件更新不会丢失
- **缓存目录**：v0.7.0 起下载目录按 `JM{漫画id}_{漫画标题}/P{章节id}_{章节标题}/` 命名，章节 ID 保证空章节名也不会撞目录；旧版目录仍可被单章命令按标题匹配，但整本下载可能会重新下载一次
- **自动清理**：发送完 ZIP/PDF 后自动删除临时文件，保留原始图片缓存，下次下载同本直接复用
- **下载进度**：整本下载时每 3 秒推送一次进度百分比
- **下载历史**：自动记录最近下载记录，用 `/jmhis` 查看；`/jmhis -all` 仅 AstrBot 管理员可用
- **收藏夹/签到**：需要配置账号密码，且只有 `owner_ids` 中的号主可以使用
- **签到状态**：按站点签到日历统计连续天数和今日状态，API 客户端也能正确显示（数据延迟时用本机签到记录兜底）
- **评论超页**：请求页码超过总页数时直接提示"已到最后一页"，不再重复返回第一页评论
- **API 客户端**：v0.6.0 起使用移动端 API 接口，功能更全（收藏添加、评论翻页、签到等），域名自动更新
- **文件限额**：本地计数只统计本插件发送的文件，其他插件/手动发送不包含在内；如果同时使用多个机器人功能，请预留余量
