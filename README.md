# AstrBot JMComic 插件

漫画站 QQ 机器人插件，基于 [jmcomic](https://github.com/hect0x7/JMComic-Crawler-Python) 库开发，支持搜索、查详情、下载并发 ZIP。

---

## 安装

1. 在 AstrBot 管理面板 → 插件 → 安装插件 → 从链接安装
2. 填入仓库地址：`https://github.com/wnzmb/astrbot_plugin_jmcomic`
3. 安装完成后，点击插件齿轮图标，填写配置：
   - 用户名：你的站点账号（可选）
   - 密码：你的站点密码（可选）
   - 镜像站域名：你能访问的镜像站（支持多个，用英文逗号分隔，自动切换可用的）
   - 下载并发数：根据自己网络调整
   - 搜索每页条数：默认10条，可改5-20

## 指令列表

| 指令 | 用法 | 功能 |
|---|---|---|
| `/jms` | `/jms 关键词 [页码] [排序]` | 全站搜索 |
| `/jma` | `/jma 作者名 [页码] [排序]` | 按作者搜索 |
| `/jmt` | `/jmt 标签名 [页码] [排序]` | 按标签搜索 |
| `/jmr` | `/jmr 角色名 [页码] [排序]` | 按角色搜索 |
| `/jmw` | `/jmw 原作名 [页码] [排序]` | 按原作搜索 |
| `/jmv` | `/jmv <id> [选项]` | 查漫画详情（带封面，可精简内容） |
| `/jmc` | `/jmc <id>` | 查看漫画评论 |
| `/jm` | `/jm <id>` | 下载整本，自动打包 ZIP 发到 QQ |
| `/jmpdf` | `/jmpdf <id>` | 下载整本，自动生成 PDF 发到 QQ |
| `/jmrank` | `/jmrank day/week/month [页码]` | 日榜 / 周榜 / 月榜 |
| `/jmfav` | `/jmfav` / `/jmfav <文件夹id>` | 收藏夹：列表/查看内容 |
| `/jmhis` | `/jmhis` / `/jmhis clear` | 查看/清空下载历史 |
| `/jmdomain` | `/jmdomain` | 查看最新可用镜像站域名 |
| `/jmupdate` | `/jmupdate` | 查看插件更新日志 |
| `/jmrand` | `/jmrand [关键词]` | 随机抽一个漫画（可指定关键词） |
| `/jm help` | `/jm help` | 查看帮助 |

## 排序参数

搜索类指令都支持排序参数，加在最后面就行。

| 参数 | 说明 |
|---|---|
| `mr` | 最新发布（默认） |
| `mv` | 最多浏览 |
| `mp` | 最多页数 |
| `tf` | 最多收藏 |
| `tr` | 评分最高 |
| `md` | 最多评论 |

**示例**：
```
/jms jk mv        # 按最多浏览排序
/jms jk 2 tf      # 第2页 + 最多收藏
/jma MrBlack mv   # 作者搜索 + 最多浏览
```

💡 搜索小提示：建议只打前几个关键词，打全容易因为网站标题简繁混杂漏结果。

## /jmv 详情精简选项

可以加参数去掉详情中的某些字段：

| 参数 | 说明 |
|---|---|
| `-author` | 去掉作者行 |
| `-work` | 去掉原作行 |
| `-role` | 去掉角色行 |
| `-tag` | 去掉标签行 |

**示例**：
```
/jmv 123456              # 正常发全部
/jmv 123456 -role        # 去掉角色
/jmv 123456 -work        # 去掉原作
/jmv 123456 -author      # 去掉作者
/jmv 123456 -role -work  # 去掉角色和原作
```

## 分页说明

- 每页显示 10 条结果
- 第 2 页 = 第 11-20 条
- 第 3 页 = 第 21-30 条
- 以此类推

回复最后会自动带下一页的指令，直接复制发送就行。

---

## 其他说明

- **数据存储**：所有下载文件和配置都保存在 `data/plugin_data/astrbot_plugin_jmcomic/` 目录下，插件更新不会丢失
- **自动清理**：发送完 ZIP 后自动删除原始图片文件，只保留打包好的 ZIP，节省硬盘空间
- **下载历史**：自动记录最近下载记录，用 `/jmhis` 查看
- **收藏夹**：需要配置账号密码才能使用收藏夹功能
