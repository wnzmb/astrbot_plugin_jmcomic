# AstrBot JMComic 测试流程（v0.7.15）

> 原则：一条命令尽量覆盖多个维度；先只读后写、先单话后整本、先正常后异常。
> 版本专项 R01–R19 是回归锚点，按改动模块选跑；F 快批 28 条命令 10 分钟跑一轮，发布前必过。
> ChatUI 只显示最终回复；中间消息（开始下载、二次确认、限额中断）需在 `backend.log` 确认。

## 0. 测试准备

### 占位符

| 占位符 | 说明 |
|---|---|
| A | 多话漫画 `JM43164`（172 话/4862 页，第1话 1390 页） |
| B | 少话漫画 `JM1228973`（4 话/185 页） |
| C | A 的第31话章节 ID `JM275013`（19 页） |
| S | 单话小文件 `JM1484418`（6 页） |
| X | 不存在 ID `999999999` |
| O/U/M | 号主 / 普通非号主 / 管理员 |

### 环境记录

插件版本、jmcomic 版本、客户端模式（API/HTML）、`pdf_page_limit`、`zip_page_limit`、`max_batch_targets`、号主身份、群/私聊、时间。开启日志。

### 通过标准

无异常堆栈；成功回复字段完整；错误有明确中文提示；文件可打开且话序正确；缓存/计数/历史一致。

## 1. F 快批（28 条命令，10 分钟一轮）

> 每条命令后标注覆盖维度。异常/改配置项单独列在 §2。

### A 冒烟与身份（5 条）

| # | 命令 | 覆盖维度 |
|---|---|---|
| A1 | `jmwhoami` | 身份判定、号主身份识别 |
| A2 | `jmtest` | 域名连通、登录态、代理配置 |
| A3 | `jmv 43164` | 详情字段完整、封面 PDF、标签/人物/作品 |
| A4 | `jmv 275013` | 章节 ID 提示父本（不展示父本详情） |
| A5 | `jmv 43164 -author -tag -pic` | 选项组合、作者/标签/封面正确去除 |

### B 搜索（6 条）

| # | 命令 | 覆盖维度 |
|---|---|---|
| B1 | `jms 纯爱 2 mv` | 排序生效（mv=最多浏览）、第2页 11-20 条、字段完整 |
| B2 | `jms 纯爱 0` | 非法页码拒绝 |
| B3 | `jms 纯爱 9999` | 超页提示（共 10000 条/最多 1000 页） |
| B4 | `jms 纯爱` | 默认第1页、标题带"（最新）" |
| B5 | `jma 博` | 作者搜索冒烟 |
| B6 | `jmt 汉化` | 标签搜索冒烟 |

> 其他搜索类型（jmr 角色 / jmw 原作）各冒烟一条即可；排序 mr=最新、mp=最多页数、tf=最多收藏、tr=评分最高、md=最多评论 与 mv 同路径，抽查一条即可。

### C 列表与排行（3 条）

| # | 命令 | 覆盖维度 |
|---|---|---|
| C1 | `jmlist 43164 2` | 话列表分页、格式 `第n话 [JM{id}] 原标题（N页）` |
| C2 | `jmc 43164` | 评论翻页、无评论提示（对 B 测） |
| C3 | `jmrank day` | 排行榜 day/week/month 冒烟 |

### D 下载核心（6 条）

| # | 命令 | 覆盖维度 |
|---|---|---|
| D1 | `jm 275013，1484418` | **中文逗号多目标**（R19）、成功 2/2、命名 `JM43164_P031.pdf` + `JM1484418_P001.pdf` |
| D2 | `jm 43164 -c 31,35,40` | 不连续话、命名 `P031,P035,P040` |
| D3 | `jmzip 1228973` | 整本 ZIP、`zip_group_size` 合并 |
| D4 | `jm 43164 -c 1:1-50` | 页段下载、命名带 `_p001-050` |
| D5 | `jmnow` | 无任务时返回"当前还没有下载" |
| D6 | `jmstop` | 协作式取消、jmnow 恢复无任务 |

> 英文逗号 `jm 275013,1484418`、重复逗号 `275013,,1484418` 与中文逗号同路径，抽查一条。

### E 账号收藏订阅（4 条）

| # | 命令 | 覆盖维度 |
|---|---|---|
| E1 | `jmcheckin` | 今日未签成功；已签提示"今日已签到"（R15） |
| E2 | `jmme` | 面板字段：签到、收藏数、状态行（已收藏显示📌） |
| E3 | `jmfav` | 收藏列表、空列表提示 |
| E4 | `jmsub 43164 list` | 订阅入口、重复订阅提示 |

### F 异常与历史（4 条）

| # | 命令 | 覆盖维度 |
|---|---|---|
| F1 | `jms` | 空参用法 |
| F2 | `jmv 999999999` | 无效 ID 提示 |
| F3 | `jm` | 无参用法 |
| F4 | `jmhis` | 历史记录、与下载一致 |

## 3. 需配置变更的项（不在快批）

> 这些要改 AstrBot 配置、重启或多账号，单独跑。

| 项 | 操作 |
|---|---|
| V03 重启持久化 | 改配置→重启→验证缓存/历史/订阅保留 |
| V04 HTML 双模式 | 切 `client_type=html` 跑 A3/D3 |
| F14 非号主拒绝 | 切到普通账号跑 `jmcheckin`/`jmfav`/`jmfav export`，应全部拒绝 |
| F19 群白名单 | 在群里跑 `jms`/`jm`，验证白名单控制 |
| F21 断网 | 断网/错误域名跑 `jmv 1228973`，应有明确网络提示 |
| R01 真正分册 | 单话 >`pdf_page_limit`（如 43164 第1话 1390 页，需时间） |
| R05 限额中断 | 调小 `daily_file_limit` 跑下载到中断 |
| R11 订阅推送 | `subscribe_interval=60`，等新话推送 |
