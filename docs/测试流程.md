# AstrBot JMComic 测试流程（v0.7.9）

> 原则：先只读后写、先单话后整本、先正常后异常、账号权限最后交叉；下载测试注意 QQ 文件限额。建议在测试群/测试账号执行，不要拿生产收藏夹和真实号主收藏做删除测试。
>
> 版本相关测试已集中到第 2 节。原 `P01–P70` 合并为 `R01–R12`，原编号保留在“合并原项”列，方便对照旧记录。
>
> ChatUI 通常只显示最终回复；下载开始状态、二次确认、限额中断等中间消息需在 QQ 或 `backend.log` 确认。下载进度改用 `/jmnow` 主动查询。

## 0. 测试准备

### 占位符

| 占位符 | 说明 |
|---|---|
| A | 多话漫画，话数 >40，有标签/人物/原作/评论 |
| B | 少话或无评论漫画，用于无评论/少话测试 |
| C | A 的第 31 话章节 ID，用于单话自动识别 |
| X | 不存在 ID，如 `999999999` |
| KW/AU/TG/RO/WK | 已知有效关键词/作者/标签/角色/原作 |
| FAV | `/jmfav` 返回的收藏夹 ID |
| SUB | 有更新话的漫画 ID，用于订阅推送 |
| O/U/M | 号主账号/普通非号主账号/管理员账号 |

### 常用实测数据

| 用途 | 数据 |
|---|---|
| 多话漫画 A | `JM43164`（172 话/4862 页） |
| 少话漫画 B | `JM1228973`（4 话） |
| 单话 C | `JM275013`（A 的第 31 话） |
| 长标题 | `JM279092`（32 话/892 页） |
| 单话小文件 | `JM1484418`（1 话/6 页） |
| 章节 ID 父漫画 | `275013 → 43164`、`1236387 → 1228973` |

### 环境记录

插件 v0.7.9、jmcomic 版本、客户端模式 API/HTML、`pdf_page_limit`、`zip_page_limit`/`zip_group_size`、`page_turn_timeout`、`request_timeout`/`client_retry_times`、`download_retry_times`/`download_retry_interval`、`login_ttl_minutes`、`max_batch_targets`、`send_cover`、`confirm_timeout`、`subscription_push_limit`、`page_turn_keyword_enabled`、`include_info_page`、`use_proxy`/`proxy_url`、`enabled_groups`、`numeric_search_as_album`、`subscribe_interval`、`history_max`、QQ 限额计数、群/私聊、时间。开启日志，记录每条命令前后限额计数。

### 通过标准

无异常堆栈；成功回复字段完整；错误有明确中文提示；分页/超页提示正确；权限拒绝正确；文件可打开且话序正确；缓存/计数/历史一致；API 与 HTML 无致命差异。

### 推荐执行批次

1. 每次更新先跑：`V01–V05` + 单话 `F07`。
2. 只读全量：`F01–F06`、`F18`。
3. 下载：先单话 `F07`，再范围/批量 `F08–F10`，最后整本和限额 `F11–F13`。
4. 账号：`F14–F17`。
5. 版本专项：`R01–R14`，改到哪个模块就跑对应 R，发布前全跑。
6. 异常与链路：`F20–F21`、`L01–L05`。
7. 清理：`/jmhis clear`、删除测试收藏、清理测试缓存、恢复配置。
