## 五、v0.7.8 收尾与重构（2026-10-23）


### 5.1 模块化拆分

- `main.py` 从 5103 行拆到约 320 行，只保留插件注册、依赖组装、24 个命令包装器和 `initialize`/`terminate`。
- 新结构：
  - `core/`：`config.py`（配置解析）、`client.py`（客户端/域名）、`state.py`（运行状态）、`downloader.py`（进度下载器）、`models.py`、`parsing.py`
  - `services/`：业务能力（下载、打包、搜索、文本、分页、历史、订阅、配额、访问控制等），不依赖 `handlers`/`main`
  - `handlers/`：按命令域拆分（`album`、`download`、`library`、`search`、`favorites`、`subscribe`、`account`、`system`、`navigation`），不依赖 `main`
  - `ui/help.py`：帮助文案
- 全部使用相对导入；`PluginSettings` 由 `main.py` 注入插件目录；`NavigationHandler` 用 dispatch 字典分发，避免 handlers 反向依赖。
- 行为冻结：命令名、别名、装饰器参数、版本号、配置 schema、缓存目录、输出文件名与 QQ 消息预算策略均未变。

### 5.2 管理员 `-all`

- 新增 `AccessService.is_admin()`，统一 `/jmhis -all`、`/jmnow -all`、`/jmstop -all` 的管理员判定：优先 `event.is_admin()`，旧事件回退 `role == "admin"`。
- `ActiveDownloadService` 增加 `tasks()` / `all_tasks()` / `iter_active()`；`/jmnow -all` 汇总全部用户任务，最多展示 20 个用户，超出提示“还有 N 个用户未显示”。
- `/jmstop -all` 停止所有用户任务并汇总成功/失败数量；`all` 不带横线也可。
- 顺带修复 `LibraryHandler.history` 属性遮蔽同名方法、导致 `/jmhis` 与翻页 dispatch 失效的问题（属性改名 `history_service`）。

### 5.3 配置默认值

- `pdf_page_limit`：100 → 200，hint 同步（整话优先，单话超限按页切分，信息页不计入页数）。
- `numeric_search_as_album`：false → true，`/jms <纯数字>` 默认直接查详情，关闭后按普通搜索处理。

### 5.4 敏感词表

- 替换顺序：先自定义词表（按词长降序，长词优先），再执行内置 `X交`/`X乳` 正则；开启繁转简时先 `zhconv` 转简体。
- 修正拼音：若干长词/易错词的拼音已校正；`性虐`/`性虐待` 统一 `nve`。
- 日文假名统一改为对应中文词拼音，并保留少量固定译名。
- 当前共 106 条；D 盘 schema 曾与 C 盘运行配置逐条一致，现已移除 schema 默认值，运行配置保留。

### 5.5 仓库清理与依赖

- 移除误提交的 AstrBot 运行残留 `data/cmd_config.json` 与 `data/t2i_templates/`（其中含本机 dashboard 密码哈希，仓库未推送）。
- `.gitignore` 增加 `data/`、`.ruff_cache/`、`.pytest_cache/`。
- `requirements.txt` 补充 `PyYAML>=6.0`（`core/config.py` 直接 `import yaml`）。

### 5.6 验证

- `ruff check`、`compileall` 通过；`main.py` 与重构前命令包装器逐行一致。
- 功能测试：`/jmnow -all`、`/jmstop -all` 管理员/非管理员分支，`/jmhis` 回归，整机装配 17 项。
- 敏感词测试：长词优先、繁简双写、假名转拼音、自定义词表增删，共 22 项。
